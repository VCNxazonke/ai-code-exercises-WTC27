Glossary of domain terms used in the application is as follows:

*Core Domain Entities & States*
- Task: The foundational unit of work in the system containing metadata such as a unique ID, title, description, and tags.
- TaskStatus: An enumeration defining the exact phase of a task's lifecycle (TODO, IN_PROGRESS, REVIEW, DONE, ABANDONED).
- TaskPriority: An enumeration dictating the importance and urgency of a task (LOW, MEDIUM, HIGH, URGENT).
- Overdue: A dynamic, runtime state applied to a task if its due date is earlier than the current system time and its status is not DONE or ABANDONED.

*System Business Rules*
- Task Abandonment: An automated cleanup policy that transitions neglected tasks into an inactive, archived ABANDONED state.
- Abandonment Threshold (days_overdue): The age limit (defaulting to 7 days) past a task's due date that qualifies it for automatic cleanup.
- Priority Protection: A systemic safeguard that permanently shields HIGH and URGENT priority tasks from being processed by automated abandonment routines.
*Architecture & Data Mechanics*
- Orchestrator (TaskManager): The centralized coordinator class in app.py that processes terminal command parameters and executes workflows across models and storage.
- TaskStorage: The data persistence manager in storage.py that maintains the active task database in memory and writes it to disk.
- Serialization (Encoding): The data translation process executed by TaskEncoder that converts complex Python objects and enums into flat JSON/text structures.
- Deserialization (Decoding): The data reconstruction process executed by TaskDecoder that extracts raw JSON data streams back into typed Python objects.
ISO 8601 Formatting: The standardized text pattern used by the application (YYYY-MM-DD) to guarantee consistent datetime parsing and file outputs.

1. Scenario: Team needs to implement a new business rule: "Tasks that are overdue for more than 7 days should be automatically marked as abandoned unless they are marked as high priority."

2. Planning: Based on my understanding from the previous parts:

AI agent and I identified the files which I would need to modify as following proposed code modifications: 

#### 1. `models.py`
Add `ABANDONED` to `TaskStatus` and add `should_be_abandoned()` to `Task`:

```python
class TaskStatus(Enum):
    TODO = "todo"
    IN_PROGRESS = "in_progress"
    REVIEW = "review"
    DONE = "done"
    ABANDONED = "abandoned"  # <-- Added

class Task:
    # ... existing code ...
    
    def should_be_abandoned(self, days_overdue=7):
        """Returns True if task is overdue by >7 days and priority is lower than HIGH."""
        if not self.due_date or self.status in (TaskStatus.DONE, TaskStatus.ABANDONED):
            return False
        
        # Exempt HIGH (3) and URGENT (4) priority tasks
        if self.priority in (TaskPriority.HIGH, TaskPriority.URGENT):
            return False
            
        overdue_threshold = datetime.now() - timedelta(days=days_overdue)
        return self.due_date < overdue_threshold
```

#### 2. `app.py`
Add `process_abandoned_tasks()` to `TaskManager`:

```python
def process_abandoned_tasks(self, days_overdue=7):
    """Scans all tasks and marks eligible overdue tasks as ABANDONED."""
    tasks = self.storage.get_all_tasks()
    abandoned_count = 0
    for task in tasks:
        if task.should_be_abandoned(days_overdue):
            task.status = TaskStatus.ABANDONED
            task.updated_at = datetime.now()
            abandoned_count += 1
    if abandoned_count > 0:
        self.storage.save()
    return abandoned_count
```
