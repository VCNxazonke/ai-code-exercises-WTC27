The key components and their responsibilities are as follows:

* **`models.py`**: 
- Defines core domain entities and enums (`Task`, `TaskPriority`, `TaskStatus`). 

- Enforces entity-level logic (e.g., `mark_as_done()`, `is_overdue()`).

* **`storage.py`**: 
- Manages persistence via JSON file (`tasks.json`). Implements `TaskEncoder` and `TaskDecoder` to handle custom date parsing and enum serialization. Provides `TaskStorage` for CRUD and filtered queries.

* **`app.py`**: Serves as the central application service (`TaskManager`). Encapsulates business logic, orchestrates data calls to `storage.py`, and exposes methods for CLI interaction.

* **`cli.py`**: Command-line interface powered by standard Python `argparse`. Handles command dispatching, input validation, and formatting for terminal output.

Scenario: Team needs to implement a new business rule: "Tasks that are overdue for more than 7 days should be automatically marked as abandoned unless they are marked as high priority."

#### 1. `models.py`
Add `ABANDONED` to `TaskStatus` and add `should_be_abandoned()` to `Task`:

```python
class TaskStatus(Enum):
    TODO = "todo"
    IN_PROGRESS = "in_progress"
    REVIEW = "review"
    DONE = "done"
    ABANDONED = "abandoned"  # <-- Added

class Task:
    # ... existing code ...
    
    def should_be_abandoned(self, days_overdue=7):
        """Returns True if task is overdue by >7 days and priority is lower than HIGH."""
        if not self.due_date or self.status in (TaskStatus.DONE, TaskStatus.ABANDONED):
            return False
        
        # Exempt HIGH (3) and URGENT (4) priority tasks
        if self.priority in (TaskPriority.HIGH, TaskPriority.URGENT):
            return False
            
        overdue_threshold = datetime.now() - timedelta(days=days_overdue)
        return self.due_date < overdue_threshold
```

#### 2. `app.py`
Add `process_abandoned_tasks()` to `TaskManager`:

```python
def process_abandoned_tasks(self, days_overdue=7):
    """Scans all tasks and marks eligible overdue tasks as ABANDONED."""
    tasks = self.storage.get_all_tasks()
    abandoned_count = 0
    for task in tasks:
        if task.should_be_abandoned(days_overdue):
            task.status = TaskStatus.ABANDONED
            task.updated_at = datetime.now()
            abandoned_count += 1
    if abandoned_count > 0:
        self.storage.save()
    return abandoned_count
```
